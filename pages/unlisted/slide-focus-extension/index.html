Slide Focus Extension

A private Chrome extension that jumps back to the most recently opened Mr. Rains slide tool tab.

Download extension ZIP

Install

  1. Download and unzip the file.
  2. Open chrome://extensions.
  3. Turn on Developer mode.
  4. Click Load unpacked and choose the unzipped extension folder.

Shortcut

  • Default shortcut: Ctrl+Shift+7.
  • To change it, open chrome://extensions/shortcuts.
  • Set the shortcut scope to Global if Chrome offers that option.

The shortcut can focus the slide tab from another Chrome window or monitor. It can also work while Chrome is in the background if the shortcut is set to Global. It cannot launch Chrome if Chrome is fully closed.
